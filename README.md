# bare-hrtime

High-resolution timers for JavaScript.

```
npm i bare-hrtime
```

## Usage

```js
const hrtime = require('bare-hrtime')

hrtime() // returns [seconds, nanoseconds]
hrtime.bigint() // returns nanoseconds
```
